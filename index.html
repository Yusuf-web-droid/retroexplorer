Retro Explorer

A lightweight Windows 98-era web browser shell built around the Internet Explorer WebBrowser control. It is designed for legacy websites, local intranet pages, and older systems that rely on classic Windows technology.

Download Setup Zip Download Batch Installer

System requirement

  • Windows 98 or later
  • Internet Explorer 4 or newer
  • 32-bit desktop app

Install

Download the zip package, extract it, and run the batch installer on a Windows machine.

Important note

This browser is meant for legacy browsing and is not suitable for modern HTTPS or sensitive data use.
